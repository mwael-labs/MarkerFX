👋 Thank you for using my plugin! QUICK GUIDE
  • Select a color slot in the UI.
  • Enter the media name you want to place (e.g. whoosh, boom).
  • Add timeline markers using the same color you selected in the UI.
  • Click Apply → matching media is automatically added to the timeline.
  • You can assign multiple media to different color slots at the same time.
  • Processed markers turn red. Red markers are ignored unless you change their color.
  • If multiple files share the same name, one is randomly selected (adds variation).
  • Important: Media files must not be inside folders (folder scanning not supported yet).
  • Important: Markers must be added to the timeline, NOT a clip.
    Deselect the clip first, then right-click the timeline → Add Marker.

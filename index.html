👋 Thank you for using my plugin! QUICK GUIDE:
  • Add markers named after media files (e.g. whoosh01.mp3) (right click the marker to edit its name)
  • Set target audio/video track index
  • Click "Apply!"
  • Markers turn red once processed. Red markers will not function unless you change their color
  • Do NOT place any files within folders (Sorry it is supported as of now)
  • You MUST add markers to the timeline, NOT the clip. You need to deselect the clip first then right click -> Add Marker
  • You can have more than one media files sharing the same name, a randomly selected one will be applied
